# lang-end-pj

一个帮助开发者通过实践项目来巩固新编程语言基础的学习资源库。

## 项目简介

当你学会了一门新的编程语言后，往往需要通过实际项目来综合运用各种基础知识，才能真正掌握这门语言。本项目提供了一系列精心设计的小项目，涵盖编程语言的核心概念和常用技术。

## 适用人群

- 刚学习完一门新编程语言语法的开发者
- 希望通过实践巩固编程基础的学习者
- 想要对比不同语言实现方式的开发者

## 项目特点

- **小而精**: 每个项目都聚焦于特定的知识点
- **循序渐进**: 从简单到复杂，逐步提升难度
- **功能完整**: 项目具备完整的 CRUD 功能
- **多语言**: 鼓励用不同语言实现相同功能

## 包含项目

所有项目位于 `projects/` 目录下，按项目名称组织，每个项目包含多种语言实现。

## 如何使用

1. 浏览 `projects/` 目录，选择一个项目
2. 查看项目的 README 了解功能和运行方式
3. 选择你熟悉的编程语言，运行现有实现
4. 尝试用另一种编程语言实现相同功能
5. 对比不同实现方式，加深理解

示例：
```bash
# 运行学生管理系统（Python 版本）
cd projects/student-manager/python
python demo.py
```
